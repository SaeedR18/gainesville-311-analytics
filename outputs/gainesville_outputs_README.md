# Outputs

Charts and visualizations generated by `analysis.R` are saved to this directory when the script is run locally.

Generated outputs include:
- `top_request_types.png` — Top 6 service request types bar chart
- `top_departments.png` — Top 6 departments by request count bar chart
- `sentiment_overall.png` — Overall sentiment word count bar chart
- `sentiment_over_time.png` — Net monthly sentiment line chart
- `wordcloud.png` — 150-term word cloud of request descriptions
- `service_request_map.png` — Geographic point map (requires Google API key)
- `density_map.png` — KDE heatmap of service request hotspots (requires Google API key)
